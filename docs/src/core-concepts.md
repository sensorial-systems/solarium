# Core Concepts

## Workspace
A Solarium workspace groups one or more programs, their IDLs, tests, and supporting crates.

## Program
A program is an on-chain Solana program written in Rust. Solarium aims to make program authoring more idiomatic and ergonomic.

## Instructions
Instructions define the callable entrypoints of your program and the accounts they operate on.

## IDL
An Interface Definition Language (IDL) describes your program's instructions and accounts in a structured way so tools can interoperate.

## Testing
Workspaces include tests that run against a local validator, enabling fast iteration.
